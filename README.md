# B&B Home Improvements: concept site

A pitch demo by LuminArch (luminarch.pro) for B&B Home Improvements, Fayetteville NC. **This is not B&B's official site. B&B has no website today.**

Live: https://bb-home-improvements-demo.vercel.app/ (temporary GitHub Pages link; noindex and robots.txt Disallow all)

- Plain static HTML, CSS and JS. Pages come from `build.py` (run `python3 build.py`).
- Reviews are real Google reviews, quoted word for word with dates. See FACTS_LOG.md.
- Placeholders are tagged in yellow.
- Design notes are in DESIGN_DNA.md. Market research is in market-research.md.
- Screenshots: screenshots/index-desktop-fold.png, screenshots/index-mobile-fold.png

GitHub Pages mirror (left on for now): https://daveo820.github.io/bb-home-improvements-demo/
